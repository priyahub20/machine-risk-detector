# Machine Risk Detector

A Machine Learning-based web application that predicts the health status of industrial machines based on operational parameters.

## Features

- Predicts Low, Medium, and High Risk
- Machine Health Report
- Health Score
- Maintenance Recommendation
- User-friendly React Interface

## Tech Stack

- React.js
- Python
- Pandas
- NumPy
- Scikit-Learn
- Random Forest Classifier

## Machine Parameters

- Temperature
- Runtime
- Vibration
- Oil Level

## Output

- Low Risk
- Medium Risk
- High Risk
- Health Score
- Recommendation

## Future Improvements

- Flask API Integration
